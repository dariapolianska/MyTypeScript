# Практична робота — Налаштування TypeScript-проєкту

Цей репозиторій містить базову структуру TypeScript-проєкту для навчальних цілей.

## Зміст

- Налаштований конфігураційний файл `tsconfig.json` з базовими параметрами компіляції.
- Каталог `src/`, у якому розміщено файл `index.ts` з простим прикладом коду на TypeScript.
- Збірка проєкту виконується в каталог `build/`.

## Опис прикладу

У файлі `src/index.ts` реалізовано невеликий приклад з використанням базових типів:
`string`, `number`, `boolean` та простої функції, яка формує текстовий опис курсу.
